Architecture

Engineered, not vibe-coded

The plugins share one library: a write-behind player cache (one SELECT per session, batched flushes, zero per-tick SQL), an idempotent credit ledger, and a service locator so each plugin degrades gracefully if the database is down. Config is a single JSON tree. Every schema change is an additive, re-runnable migration.

The website talks to the exact same MariaDB through a swappable data source, with a signed-token agent bridge to the game servers. RBAC and schema validation on every admin route. It runs four servers on an 8 GB box.
